## Ключевые разделы для компании PropDevelopment

### Управление доступом
- Клиенты видят чужие данные в личном кабинете
- Некоторые API позволяют внешним пользователям выполнять действия и получать данные, к которым у них нет доступа
- Отсутствие системного контроля за передаваемыми данными между IT-продуктами

### Безопасность данных
- Нарушен контроль данных
- Нет контроля между точками регистрации новых клиентов
- Предоставление персональных данных в API
- Необходимость соответствия 152-ФЗ
- Жалобы клиентов на отображение чужих данных в личном кабинете

### Защита инфраструктуры
- Гибридная инфраструктура требует защиты и разграничения сегментов сети
- Доступ внешних пользователей через firewall
- Хранение чувствительной информации требует шифрования, безопасного удаления

### Безопасность API и внешних интеграций
- Предоставление персональных данных в API
- Некоторые API позволяют внешним пользователям выполнять действия и получать данные, к которым у них нет доступа
- API управляющих компаний без единых политик по безопасности
- Нет системного контроля за передаваемыми данными
- Контракты API содержат персональные данные
- Отсутствие системного контроля за передаваемыми данными
- Планы активно развивать свои и партнёрские сервисы для покупателей и жильцов

### Управление инцидентами
- Недавно у конкурента произошла утечка данных. Аудит безопасности должен помочь компании предотвратить подобные инциденты
- Специалисту по ИБ не передают всю информацию об изменениях
- Поставлена цель - повысить уровень удовлетворённости клиентов
- Проведение комплексного аудита безопасности
- Нет автоматизированного оповещения о инцидентах, о них узнаем от пользователей
- Необходимость отслеживания несанкционированного доступа к данным
- Изменения в составе руководителей IT-команд нарушили процесс передачи информации между командами
