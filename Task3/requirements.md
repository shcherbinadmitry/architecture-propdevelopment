## Список требований к внешним интеграциям

### Требования к безопасности:
* Изоляция - доступ внешних API должен быть ограничен только до систем взаимодействующих с ними
* Минимальные привилегии - внешние API должны иметь доступ только к API и данным, необходимым для работы интеграции
* Сквозное шифрование - все API должны общаться с системами PropDevelopment по защищенным каналам с шифрованием TLS
* Все ключи от интеграций с API партнеров должны храниться в защищенном хранилище (HashiCorp Vault), проходить регулярный аудит
* Все данные от API партнеров должны валидироваться и очищаться от лишних данных на уровне DTO
* Должен быть разработан протокол уведомления о инцидентах безопасности
* Получить от парнеров гарантии о соответствии 152-ФЗ, если для работы интеграции требуется пересылка персональных данных
* Хранение персональных данных в отдельных зашифрованных хранилищах. Сырые данные, поступающие в DWH должны приходить в де-персонализованном виде
* При необходимости хранения файлов для реализации интеграций (номера, биометрия, фото для facial-recognition), должны храниться в S3 хранилище во внутреннем защищенном контуре без прямой привязки к конкретному клиенту (использование хеширования)

## Протоколы аутентификации и авторизации:
* Использование JWT (JSON Web Tokens) для аутентификации и авторизации пользователей.
* Внедрение MFA для доступа к приложению tenant-app и использования интеграций
* Проверка подлинности запросов между системами PropDevelopment

## Организация взаимодействия между системами:
* REST API для общения между мобильным приложением PropDevelopment и внутренними сервисами "Умного дома".
* Изоляция прямого взаимодействия с партнерами через отдельное приложение, которое реализует интеграцию по протоколам SPI/WS с партнерскими устройствами
* Фиксированные DTO для взаимодействия с парнерскими системами.
* Логирование, фиксация ошибок по работе интеграций в единой системе (ELK), обфускация персональных данных при логировании
* Внедрение версионности в API для гарантии функционирования интеграций с партнерами
